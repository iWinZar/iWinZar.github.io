# evanbonhoure.me

Portfolio statique (HTML / CSS / JS, sans framework ni build), hébergé sur GitHub Pages.

- `index.html` : version française. `en/index.html` : version anglaise.
- `assets/style.css`, `assets/main.js` : styles et scripts (écran de démarrage, terminal, schémas animés, ciel selon l'heure, effets d'eau, menu mobile, démo).
- `CLAUDE.md` : règles du site, fonctionnement détaillé, journal des changements et liste de ce qui reste à faire.
- `assets/fonts/` : Source Sans 3 (licence SIL OFL), hébergée sur le site.
- `_modeles/writeup.html` : modèle de page de write-up. Le dossier commence par `_`, donc GitHub Pages ne le publie pas. Pour écrire un write-up, copier ce fichier dans `writeups/`, le remplir, puis remplacer les boutons « Write-up bientôt » de l'accueil par un lien.
